Online Payment Fraud Detection Using Machine Learning

A comprehensive machine learning system designed to identify and flag anomalous transactions in simulated financial environments. This documentation outlines the architecture, methodologies, and limitations of the FraudGuard project.

warning

Important Disclaimer

FraudGuard is strictly an academic prototype designed for educational and research purposes. It operates on simulated, synthetic datasets and is not intended or equipped for processing real financial transactions, sensitive personal data, or integration into live production banking environments. Any data presented within this interface is purely illustrative.

target

flag Project Objective

The primary goal of this project is to develop a robust, high-precision machine learning model capable of distinguishing between legitimate and fraudulent online payment transactions in real-time.

We aim to address the critical challenge of class imbalance inherent in fraud detection datasets (where legitimate transactions vastly outnumber fraudulent ones) while minimizing false positives to reduce user friction during checkout processes.

  • Achieve an F1-score > 0.85 on the minority (fraud) class.
  • Maintain inference latency under 200ms per transaction.
  • Provide interpretable risk scoring for analyst review.

Feature Engineering

Time-based aggregations (e.g., velocity of transactions per user within 1h, 24h windows), device fingerprinting abstraction, and geographical distance calculations between IP location and shipping address.

Handling Imbalance

Implementation of Synthetic Minority Over-sampling Technique (SMOTE) combined with Edited Nearest Neighbours (ENN) to create a balanced training set without introducing severe overfitting.

Normalization

Robust Scaling applied to continuous variables (like transaction amount) to mitigate the influence of extreme outliers common in financial data.

model_training Algorithms Evaluated

Multiple models were trained and cross-validated. The final deployment utilizes an ensemble approach to balance recall and precision.
